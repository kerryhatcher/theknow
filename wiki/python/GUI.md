 # Python GUI projects to investigate

 1. Kivy - Cross-platform Python framework, supports iOS, Android, Windows, macOS, Linux. Uses its own widget toolkit. Can be deployed on web via KivyMD
    or other methods.
 2. BeeWare/Toga - Cross-platform native apps from Python. Supports macOS, Windows, Linux, iOS, Android, and web.
 3. Flet - Built on Flutter, supports Windows, macOS, Linux, web, iOS, Android from Python.
 4. PyQt/PySide - Qt framework bindings. Supports Windows, macOS, Linux. Can target web via Qt for WebAssembly (limited). iOS support is limited.
 5. Remi - Pure Python library that converts Python widgets to HTML, runs as a web app.
 6. NiceGUI - Python UI framework for web, also can be packaged as desktop app.
 7. Reflex (formerly Pynecone) - Python web framework that compiles to React.
 8. Eel - Python library for making simple Electron-like offline HTML/JS GUI apps.
 9. Dear PyGui - GPU-accelerated Python GUI framework.
 10. Tkinter - Built-in, but only desktop.
